# 产品需求

## 背景与推导

长篇世界中的人名、地名和用语会反复出现。一次性命名表保不住音系、词根与词形之间的关系；改一条规则也容易让旧名字与例句失去依据。工程保存明确规则与派生步骤，Agent创造语言和表达，作者决定它的气质与文化含义。

生成成本和等待时间会变化，但固定作品、历史依据、具体意见与连续审阅仍需长期积累。固定工程避免让模型每轮重建结构；结构化数据与多种阅读方式共用同一专业成果。插件按需安装，让作者提出目标、Agent操作工程、作者在适合的工作面阅读和选择。

## 定义与首版

构造语言工坊是河图洛书JS／TS专业插件。让虚构语言的音位、正字、词根、形态规则和命名派生保持可解释、可复核。用户包括独立作者、编辑与外部Agent。默认旅程：读取固定世界依据 → 明确音位和正字 → 编制词根词类 → 定义有限规则 → 预览逐步派生 → 固定名称及例句 → 修改后复核 → 词典与命名接续。

首版包含完整专业维护、准确来源回读、专业方案、固定意见、确定性检查和改稿影响、上下文、固定交接、JSON／Markdown／HTML工程及专业阅读本。功能必须经机器入口执行，作者可以自然语言提出目标，也保留人工优化入口。

## 边界

世界构建负责制度、历法与正式设定，本包负责语言内部关系与确定性派生；正式人物及名称采用归宿主。不是机器翻译器、语音合成、任意音变DSL或语言学正确性认证。正文、正式设定、素材、采纳与定稿由宿主和作者掌握，不另建数据库、模型渠道或内部Agent。

成功以真实创作、审阅、返工及下一轮接续为准，安装、动作数或文件存在都不足以代表完成。开发与验收状态只由08维护。
