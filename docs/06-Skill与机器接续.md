# Skill与机器接续

包内hetu-language-studio由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：读取固定世界依据 → 明确音位和正字 → 编制词根词类 → 定义有限规则 → 预览逐步派生 → 固定名称及例句 → 修改后复核 → 词典与命名接续。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

词条以显式音位ID序列记录，音位正字唯一不强制、派生保留ID边界。规则只支持明确音位序列的前缀、后缀、替换；替换单轮从左至右非重叠执行，不执行正则或脚本、不重复直到稳定。每次最多30规则、256音位，空匹配拒绝；规则可限定词类，不满足时明确拒绝。命名派生固定词根与有序规则摘要，保存逐步音位及正字结果；改规则后旧派生待复核而保留。例句按明确词条/派生引用和逐词注释，不用字符数推断音节或假装语言学认证。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
