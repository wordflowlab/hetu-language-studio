# 创作流程与反例

为旧站世界建立三个音位和两个词根，用前缀表示地名，再加后缀构成居民称呼；比较规则顺序，修改正字后复核旧人名和例句。

词条以显式音位ID序列记录，音位正字唯一不强制、派生保留ID边界。规则只支持明确音位序列的前缀、后缀、替换；替换单轮从左至右非重叠执行，不执行正则或脚本、不重复直到稳定。每次最多30规则、256音位，空匹配拒绝；规则可限定词类，不满足时明确拒绝。命名派生固定词根与有序规则摘要，保存逐步音位及正字结果；改规则后旧派生待复核而保留。例句按明确词条/派生引用和逐词注释，不用字符数推断音节或假装语言学认证。

世界构建负责制度、历法与正式设定，本包负责语言内部关系与确定性派生；正式人物及名称采用归宿主。不是机器翻译器、语音合成、任意音变DSL或语言学正确性认证。

## 固定接续

读取已有成果及全部必要来源，明确未读范围。新意见固定具体目标摘要，旧意见不能默套新稿；返工后通过实际依据动作重新固定并回读。create_handoff返回BasisRef，不是SourceRef；通过公开资料任务保存包含Owner、对象、修订、sha256及专业内容的派生快照，下游任务固定原资料与派生快照并完整回读。不同作品分别获权，旧修订和未知操作保持原义。

Lexurgy展示音变顺序与环境，PolyGlot区分词典、音系和派生。本包研究结构后独立实现有限音位序列规则，不复制GPL音变引擎，也不宣称其DSL兼容。
